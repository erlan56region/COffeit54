# coffeeIT — живой сайт + 5 вариантов дизайна

Бренд **coffeeIT**: кофейня для разработчиков, пространство для работы и IT-интегратор (разработка, закупка серверов и лицензий, безопасность, интеграции, поддержка) + собственные проекты и спонсорство.

**Главная страница** — `index.html`: навигатор, сверху выделен финальный живой вариант.

| Файл | Что это |
|---|---|
| **`coffeeit-live.html`** | ★ **финальный сайт**: 8 разделов, активные анимации, вкладка «Спонсорство», фотографии |
| `coffeeit-v1.html` | «Код и зерно» — светлый редакционный премиум |
| `coffeeit-v2.html` | «Смена» — тёмный графит + лайм, хай-тек |
| `coffeeit-v3.html` | «Coffee first» — нео-брутализм |
| `coffeeit-v4.html` | «Terminal» — моно-шрифт, консоль, YAML |
| `coffeeit-v5.html` | «Build & Brew» — базовая версия финального варианта (без анимаций и спонсорства) |
| **`coffeeit-v6.html`** | ★ «Agency Editorial» — светлое премиум-агентство: огромные заголовки, бенто-фото, воздух |
| **`coffeeit-v7.html`** | ★ «Noir Premium» — тёмный агентский брутализм: крупная типографика, медный акцент |

## Варианты 6 и 7 — в стиле диджитал-агентств

Оба варианта задуманы как «сайт, который хочется купить»: профессиональные фотографии, спокойная сетка, много воздуха, крупная типографика и живые детали.

- **v6 «Agency Editorial»** — светлый премиум: белый фон, антиква в акценте, глубокий зелёный, тонкие линии, услуги строками, проекты фото-карточками с раскрытием при наведении, блок «команда», живая панель кофейни.
- **v7 «Noir Premium»** — тёмный агентский брутализм: гигантские заголовки (одна строка контурная), медный акцент, проекты горизонтальными строками, спонсорство карточками и тарифной сеткой.

В обоих: 8 разделов, анимации (счётчики, параллакс, бегущая строка, живые цифры), вкладка «Спонсорство» с пятью будущими проектами, мерч с фото, корзина и формы.

## Оформление варианта 5

На странице `coffeeit-v5.html` под шапкой есть раздел «Оформление сайта»: пять цветовых схем и переключатель новогоднего режима. При первом посещении праздничный режим включён; выбор сохраняется в браузере. Снег автоматически отключается при системной настройке уменьшения движения. Новогодние фотографии встроены в HTML, а исходные изображения и код переключателя находятся в `source/`.

## Что «живого» в финальном сайте

- **Цифры считаются сами** — при прокрутке значения анимируются (120+, 9 лет, 99,98%, −38%);
- **живая статистика** — гостей в кофейне, свободные места и чашки за сегодня меняются каждые 2–4 секунды;
- **бегущие строки** — направления, проекты и статус кофейни;
- **печатная машинка** — подзаголовок набирается посимвольно с мигающим курсором;
- **параллакс** — фотографии мягко двигаются при прокрутке;
- **появление блоков** с задержкой, подсветка строк услуг, наведение на карточки;
- всё уважает `prefers-reduced-motion` (для тех, кто отключает анимации в системе).

## Фотографии

Сгенерированные изображения встроены прямо в HTML: кофейня и бар, рабочая зона, мерч (худи, кружки, кепки, шопперы), а также все пять будущих проектов.

## Публикация на GitHub Pages

1. https://github.com/new → имя `coffeeit`, **Public**, без README.
2. «uploading an existing file» → перетащите **содержимое** этой папки (файлы + папку `source`).
3. Commit changes → Settings → **Pages** → Deploy from a branch → `main` / `/ (root)` → Save.
4. Через 30–60 секунд: `https://<логин>.github.io/coffeeit/` (главная — навигатор, финальный сайт — по ссылке сверху).

## Правка контента

Всё в одном объекте `window.CI_DATA` в начале HTML-файла: контакты, услуги, кейсы, цены, товары, меню и блок `sponsorship` (проекты, пакеты, FAQ).

Исходники и сборщик — в `source/`:

```bash
cd source
python3 build.py v5     # собрать v5 в source/coffeeit/coffeeit-v5.html
```

Исходники сборщика доступны для v1–v5. Файлы `coffeeit-live.html`, `coffeeit-v6.html` и `coffeeit-v7.html` редактируются отдельно; сборка v5 не обновляет их автоматически.

⚠️ Перед публикацией замените демонстрационные контакты, адрес, цены, кейсы и суммы спонсорских пакетов на реальные.
