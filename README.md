# coffeeIT — один сайт, восемь обликов

Бренд **coffeeIT**: кофейня для разработчиков, пространство для работы и IT-интегратор (разработка, закупка серверов и лицензий, безопасность, интеграции, поддержка) + собственные проекты и спонсорство.

Главная страница `index.html` — не каталог ссылок, а **сам сайт**: он показывает один из восьми дизайнов на весь экран и через минуту бездействия плавно меняет облик. Внутри — те же разделы, кейсы, магазин и формы.

## Как это работает

- Открываете `index.html` — сразу загружается один из восьми обликов (случайный, либо тот, что запомнился).
- **Минута бездействия** (скролл, клик, ввод, движение мыши) — и сайт сам, плавно, переходит в другой дизайн.
- Любое действие сбрасывает таймер: пока сайт читают, он не меняется.
- Смена случается **только на главной странице**. В разделах «Услуги», «Кейсы», «Магазин» и т. д. облик замирает, чтобы не мешать — в капсуле внизу видно «пауза — раздел …», клик по этой подписи возвращает на главную.
- Открытая корзина, мобильное меню или неактивная вкладка браузера тоже ставят смену на паузу.
- Последовательность обликов **случайная, но без повтора** подряд. Переходы чередуются: шторка → растворение → слайд → микс, чтобы глаз не привыкал.

### Пульт внизу экрана

| Элемент | Что делает |
|---|---|
| Кольцо с номером | Обратный отсчёт до смены, номер и название текущего облика |
| Подпись под номером | Кто следующий и через сколько; клик по «пауза — раздел …» ведёт на главную |
| `→` | Сменить облик сейчас (`→` или `←` на клавиатуре) |
| Круг из 8 точек | Мгновенный выбор любого облика |
| Пауза/восемь точек | Автосмена вкл/выкл (`пробел`), панель «Все облики» (`Esc` — закрыть) |
| «музыка» (слева, вертикально) | Панель Яндекс Музыки: вход через профиль и плеер (`M`) |

В панели дополнительно: интервал молчания (30 с / 1 мин / 2 мин), тип перехода, ссылка на текущий облик (`?skin=v7`) и открытие любого облика как отдельной страницы.

### Музыка (слева)

На левом краю — вертикальная кнопка **«музыка»**. Она открывает панель с официальным плеером **Яндекс Музыки** и входом через профиль Яндекса.

- **Плеер.** Вставьте ссылку на альбом, трек или плейлист (`https://music.yandex.ru/album/…`, `/track/…`, `/users/…/playlists/…`) либо готовый `<iframe>` из меню «Поделиться → HTML-код» — виджет отрисуется прямо в панели. Ссылки нормализуются в формат `music.yandex.ru/iframe/…`; чужой домен отклоняется. Последний плейлист запоминается (`localStorage`, ключ `ci_music_v1`), есть кнопки «Стоп» и демо-пресеты. Воспроизведение и права остаются на стороне Яндекса: это его виджет в рамке.
- **Вход через профиль.** Кнопка «Войти через Яндекс» уводит на `oauth.yandex.ru`, возвращает токен в адресе (`#access_token=…`), после чего с `login.yandex.ru/info` подтягиваются имя и аватар. Запрашиваются только права `login:info` и `login:avatar` — пароль сайт не видит и не хранит. Выход очищает сохранённый токен.

Чтобы вход заработал, нужен **свой client_id** (одна строка в начале скрипта `index.html`, объект `YM`):

1. https://oauth.yandex.ru/client/new — создайте приложение.
2. Включите права **login:info** и **login:avatar**.
3. Redirect URI укажите ровно тот, где лежит сайт, например `https://ваш-домен/index.html` (или `http://localhost:8080/index.html`).
4. Полученный `client_id` впишите в `clientId: ''` объекта `YM`.

Пока `client_id` не указан, панель честно показывает инструкцию вместо мнимого «вы вошли». Без входа плеер тоже работает — публичные треки и плейлисты открываются.

Горячие клавиши: **M** — открыть/закрыть музыку, **Esc** — закрыть.

### Ссылки и параметры

```
index.html                восемь обликов, автосмена
index.html?skin=v7        начать с конкретного облика и закрепить его
index.html?interval=30    тишина перед сменой, секунды (минимум 10)
index.html?auto=0         открыть с выключенной автосменой
index.html?transition=veil|fade|slide|mix   зафиксировать один тип перехода
index.html?reset=1        сбросить сохранённые настройки
```

Выбор облика, интервал и тип перехода запоминаются в браузере (`localStorage`, ключ `ci_chameleon_v1`).

## Четыре перехода

1. **Шторка** — цветная панель в цвет нового облика проезжает по экрану, за ней уже другой дизайн.
2. **Растворение** — старый облик тает в размытие и лёгкое уменьшение, новый проявляется.
3. **Слайд** — новый облик поднимается снизу «шторой» секций, старый уезжает вверх.
4. **Микс** — цветная вспышка, шторка и каскадное появление блоков нового облика.

В режиме «все» переходы идут по кругу; в панели можно закрепить один. При системной настройке «уменьшить движение» (prefers-reduced-motion) остаётся только мягкое растворение без шторки и каскадов.

## Что общего у всех обликов

Восемь разделов (Главная, Услуги, Кейсы, Вендоры, Пространство, Спонсорство, Мерч, Контакты — в v1 семь, без спонсорства), логотип-кружка, магазин с фильтрами и корзиной (сохраняется после перезагрузки), оформление заказа и заявок через почтовое приложение, бронирование места, кейсы с раскрывающимися подробностями, адаптивная вёрстка под телефон.

Первый загруженный облик «живёт» в iframe, поэтому стили восьми вариантов не конфликтуют друг с другом.

## Структура проекта

```
index.html                     ★ оболочка: восемь обликов, переходы, музыка
coffeeit-v1…v7.html            сами облики (автономные страницы)
coffeeit-live.html             живой финальный вариант
source/bridge.js               «мостик»: активность, раздел, прокрутка, каскад
source/inject_bridge.py        встраивает мостик во все облики (идемпотентно)
source/build.py                сборщик v1–v5 из source/src
source/src/                    исходники CSS/JS и данные (window.CI_DATA)
source/photos/, source/images/ фотографии для сборки
```

Если облик пересобран или заменён сторонним файлом, выполните:

```bash
python3 source/inject_bridge.py     # вернуть каждому облику «мостик»
```

Мостик нужен, чтобы оболочка знала о действиях посетителя и разделе. Без него сайт работает, но автосмена не будет сбрасывать таймер и может сработать в разделе.

## Правка контента

Всё в одном объекте `window.CI_DATA` в начале каждого HTML-файла: контакты, услуги, кейсы, цены, товары, меню и блок `sponsorship` (проекты, пакеты, FAQ). Сборка и установка зависимостей не нужны.

```bash
cd source
python3 build.py v5     # пересобрать v5 в source/coffeeit/coffeeit-v5.html
```

Исходники сборщика есть для v1–v5. Файлы `coffeeit-live.html`, `coffeeit-v6.html` и `coffeeit-v7.html` редактируются отдельно.

⚠️ Перед публикацией замените демонстрационные контакты, адрес, цены, кейсы и суммы спонсорских пакетов на реальные.

## Публикация на GitHub Pages

1. https://github.com/new → имя `coffeeit`, **Public**, без README.
2. «uploading an existing file» → перетащите **содержимое** этой папки (файлы + папку `source`).
3. Commit changes → Settings → **Pages** → Deploy from a branch → `main` / `/ (root)` → Save.
4. Через 30–60 секунд: `https://<логин>.github.io/coffeeit/` — сразу открывается сайт-хамелеон.

Все облики лежат рядом с `index.html`, поэтому iframe-оболочка работает и на статическом хостинге, и при открытии папки с диска.
